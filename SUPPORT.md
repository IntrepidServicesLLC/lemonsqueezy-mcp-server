# Support and security reporting

For setup or integration problems, open a [repository issue](https://github.com/IntrepidServicesLLC/lemonsqueezy-mcp-server/issues) with the server version, Node version, entry point (`dist/index.js` or guarded host), expected environment, exact reproduction steps, and sanitized error text. State whether the problem appears in the no-secret example. Do not include API keys, grants, customer data, or production logs.

For a suspected vulnerability, use the repository's **Security** tab and its private vulnerability reporting flow if available. If that flow is unavailable, open a generic issue asking the maintainers for a private reporting channel. Do not put exploit details or sensitive evidence in the public issue. The maintainers can then arrange a private exchange.
